# 🚀 Neon Space Dodger

A simple browser arcade game where you control a spaceship, dodge incoming asteroids, and try to survive for as long as possible.

The game gets progressively faster, so every run becomes a little harder than the last one.

## 🎮 Features

- Smooth spaceship movement
- Randomly generated asteroids
- Increasing difficulty
- Score and high-score tracking
- Animated starfield
- Particle effects
- Pause and restart
- Keyboard controls
- Mobile controls
- Responsive interface
- No external libraries or dependencies

## 🕹️ Controls

**Desktop**

- `←` / `→` — Move
- `A` / `D` — Move
- `Space` — Pause / Resume
- `P` — Pause / Resume
- `Enter` — Start / Restart

**Mobile**

Use the left and right buttons shown on the screen.
